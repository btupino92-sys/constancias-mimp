# Gestor de Constancias MIMP — integrado

Aplicación estática para GitHub Pages: pasos 1–4, asociación automática de PDFs firmados que terminan en `[F]`, QR dentro del PDF y paso 5 con dos vías: Microsoft Graph (Outlook web / nuevo / clásico conectado a Exchange Online) y paquete de borradores para Outlook clásico local.

Publicación: subir **contenido** de esta carpeta en raíz del repositorio. En Settings > Pages elegir rama main y /(root). Leer `GUIA_INTEGRAL.md` antes de habilitar envío real. Se requiere autorización de OGTI para Microsoft Graph.
